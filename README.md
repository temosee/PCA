# Домашнее задание 2: Калькулятор разделения счета

**ФИО:** Полатинский Артем  
**Группа:** ПИКД(7)

**Описание:**  
Разработано приложение SplitMate - калькулятор разделения счета для компаний. Приложение позволяет рассчитать итоговую сумму с учетом чаевых и разделить ее поровну между участниками. Реализован механизм сохранения истории последних расчетов для быстрого доступа к результатам.

## Как запустить
1. Склонируйте данный репозиторий.
2. Откройте проект в Android Studio (рекомендуется версия Ladybug или новее).
3. Убедитесь, что в системе установлен Android SDK 36 (приложение использует compileSdk 36).
4. Нажмите кнопку Run.

## Реализованный функционал
### Обязательные требования:
- Навигация: Реализовано 4 экрана: Home (Приветствие), Input (Ввод данных), Result (Детализация расчета), History (История).
- Архитектура:
    - Использование ViewModel для хранения состояния ввода и логики расчетов.
    - Передача данных между экранами через аргументы навигации (calcId).
- Ввод данных: Поля с валидацией суммы чека и количества человек (кнопка расчета активна только при корректных данных).
- Экран Result: Детальное отображение суммы с каждого человека, размера чаевых и общего итога.

### Бонусы:
- Jetpack Compose + Material3: Современный интерфейс с использованием ElevatedCard и адаптивной верстки.
- Navigation Compose: Маршрутизация через NavHost с использованием Sealed Class для описания маршрутов.
- История расчетов: Хранение и отображение последних 5 расчетов в памяти ViewModel с возможностью быстрого перехода к деталям.
- Полная локализация: Интерфейс приложения реализован на русском языке.
